# Devharshthakur Tap

## How do I install these formulae?

`brew install devharshthakur/tap/<formula>`

Or `brew tap devharshthakur/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "devharshthakur/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
